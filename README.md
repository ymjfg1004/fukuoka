# 후쿠오카·유후인 가족여행

2026.10.04~10.07 일정표, 예약 정보, 점검 포인트, 준비물을 담은 정적 페이지입니다.

- 사이트: https://fukuoka-m4fy.vercel.app
- 구성: `index.html` 한 장 + `vercel.json` (빌드 과정 없음)

## 배포

Vercel 프로젝트가 이 GitHub 레포와 연결되어 있습니다.
`main` 브랜치에 push 또는 merge 하면 자동으로 배포됩니다.
다른 브랜치는 Preview 주소만 만들어지고 실서비스에는 반영되지 않습니다.

## 쇼핑 탭 (선물 · 구매리스트)

하단 "쇼핑" 탭 안에서 "🎁 선물"과 "🛒 구매리스트"를 오갑니다. 두 목록은 같은 방식으로 폰에서 직접 적고 사진을 올립니다. 산 것은 체크하면 글에 줄이 그어지고 수량·금액이 흐려집니다(사진은 그대로 보입니다).

- 항목마다 수량(1~99)을 정할 수 있습니다. 추가할 때 입력하고, 목록에서 −/＋ 버튼이나 숫자 칸으로 언제든 바꿉니다. 탭 위쪽 뱃지는 남은 건수와 개수(예: `2건 · 3개 남음`)를 보여 줍니다. 수량이 없는 예전 항목은 1개로 봅니다.
- 항목마다 개당 가격(엔)을 적을 수 있습니다. 가격이 있는 항목을 체크(산 것)하면 가계부(예약·비용 탭 → "비용·지출"의 "현지 지출 기록")에 `쇼핑` 지출로 자동으로 들어갑니다(금액 = 개당 가격 × 수량). 날짜는 체크한 날(여행 전이면 10/4)로 잡히고, 항목 안의 "가계부" 선택칸에서 바꿀 수 있습니다. 체크를 풀거나 항목을 지우면 가계부에서도 빠집니다. 가계부의 ↗ 버튼으로 해당 항목으로 이동합니다. 가격이 없는 항목은 가계부에 들어가지 않습니다.
- 항목 하나에는 사진이 한 장입니다. 사진을 여러 장 고르면 한 장마다 항목이 하나씩 만들어지고, 입력한 글·수량·금액이 모두에게 똑같이 들어갑니다(항목에서 하나씩 고치면 됩니다). 항목은 왼쪽에 사진, 오른쪽에 글·수량·금액이 세로로 놓입니다. 사진을 여러 장 가진 예전 항목은 처음 열 때 한 장씩 나뉩니다(금액은 첫 항목에만 남김).
- 이름만 먼저 적어 두고 사진은 나중에 올릴 수 있습니다. 사진이 없는 항목은 왼쪽에 "📷 사진 추가" 칸이 보이고, 눌러서 한 장 올리면 그 항목의 사진이 됩니다(사진을 지우면 칸이 다시 나타납니다).
- 글은 `localStorage`(선물 `g_list`, 구매리스트 `buy_list`)에 저장됩니다. 서버나 레포에는 올라가지 않습니다.
- 사진은 `IndexedDB`(`fukuoka-gifts`)에 **순수 바이트(ArrayBuffer)** 로 저장합니다. 아이폰 사파리에서 Blob/File을 그대로 넣을 때 나는 오류를 피하기 위해서입니다. 연결이 끊기면 다시 열어 한 번 재시도합니다.
- IndexedDB를 쓸 수 없는 환경(비공개 모드, 일부 앱 내 브라우저)에서는 작게 줄인 사본(긴 변 1280px)을 `localStorage`(`gi_<id>`)에 넣습니다. 그것도 안 되면 이유(예: `QuotaExceededError`)를 팝업으로 알려 줍니다.
- 작은 사진은 **원본 그대로** 저장하고, 1.5MB를 넘거나 긴 변이 2560px을 넘는 사진은 자동으로 화소를 줄여 JPEG로 저장합니다(보기 화면에 "용량 줄임" 표시).
- 사진을 누르면 저장된 크기 기준 1:1(이미지 픽셀 ÷ 화면 배율)로 열립니다. 목록용 작은 미리보기(최대 480px)는 따로 만듭니다.
- 주소(도메인)별로 따로 저장되므로 Preview 주소와 실서비스 주소의 데이터는 서로 보이지 않습니다.

## 새 버전 알림

`index.html`의 `<meta name="app-version">` 값과 맨 아래 "버전 …" 표시가 같은 값입니다. 열어 둔 탭에서 앱으로 돌아오면(또는 열고 1.5초 뒤) 서버의 최신 `index.html`과 이 값을 비교해서, 다르면 "새 버전이 나왔어요 · 새로고침" 배너를 띄웁니다. 배포 때 이 값을 바꾸면 됩니다.

## 백업 · 복원 (쇼핑 탭 맨 아래)

글·사진·지출 기록·체크 표시는 모두 브라우저 저장소에만 있어서, 사파리 비공개 탭, 홈 화면 앱, 다른 주소(도메인), 사이트 데이터 삭제 때는 따로 보이거나 사라집니다.

- **쇼핑 탭 맨 위의 "💾 저장" 버튼**은 아래 "백업 파일 저장"과 같은 일을 합니다. 옆에 "마지막 저장: 날짜"가 보이고, 저장한 뒤 목록이나 지출이 바뀌면 "이후 바뀐 내용 있음"이 빨갛게 뜹니다.
- **백업 파일 저장**: 목록, 지출, 체크 표시, 사진(원본 포함)을 한 개의 `fukuoka-backup-날짜.json`으로 저장합니다(공유 시트가 되면 공유 시트, 아니면 다운로드).
- **백업 불러오기**: 파일을 고르면 이 폰에 없는 항목·지출·사진만 합칩니다(같은 항목은 그대로, 두 번 불러와도 중복 없음). 다른 브라우저에 남아 있는 목록을 옮길 때도 이 방법을 씁니다.
- 열어 보면 현재 주소, 이 브라우저에 처음 저장된 때, 저장된 개수가 보입니다. "처음 저장된 때"가 최근으로 나오면 저장소가 비워진 것입니다.
- 저장에 실패하면(저장 공간 부족, 저장이 막힌 브라우저) 화면 위에 빨간 경고가 뜹니다.

## 일정 편집 (일정 탭)

일정 탭의 "✏️ 일정 편집"을 누르면 시간표를 폰에서 바꿀 수 있습니다. 하단의 "전체 일정" 모아보기는 없앴습니다(날짜 탭으로 하루씩 봅니다).

- **순서 바꾸기**: 항목 오른쪽 `≡`를 손가락으로 끌어서 옮깁니다(화면 위·아래 끝에 가져가면 자동으로 스크롤). 키보드는 `≡`에 포커스를 두고 ↑↓.
- **추가**: 맨 위의 "＋ 맨 위에 추가", 각 항목 아래의 "＋ 아래에 추가"로 그 자리에 넣습니다. 장소 이름을 적으면 구글지도 링크가 붙습니다.
- **고치기·삭제·다른 날로 이동**: `✎`를 누르면 시간·내용·메모·날짜·"선택 항목" 표시를 고치거나 삭제할 수 있습니다. 날짜를 바꾸면 그 날의 맨 아래로 옮겨집니다. 주소 블록은 항목을 옮겨도 함께 따라가고, "주소 지우기"로 뺄 수 있습니다.
- **되돌리기**: "↩ 이 날 처음으로"로 그 날만 원래 일정으로 돌립니다.
- **저장**: 고친 날은 `localStorage`의 `plan_edit`에 날짜별로 통째로 저장됩니다(고치지 않은 날은 이 레포의 일정 그대로). 레포의 기본 일정을 나중에 바꿔도 고친 날에는 반영되지 않습니다. 백업 파일에도 들어가고, 불러올 때는 이 폰에서 고치지 않은 날만 가져옵니다.

## 예약·비용 탭

아래 탭이 "예약·비용"이고, 안에서 ✈️ 항공권 / 🚗 렌트카 / 🏨 숙소 / 🍽️ 음식점 / 🛂 비짓재팬 / 🚕 우버 / 💴 비용·지출로 나뉩니다. 각 분류에는 예약 카드(상태 뱃지, 날짜·시간, 예약번호, 금액, 취소 규정, 주소·맵코드·지도 링크)가 있고, 맨 아래 점선 칸에 "알려 주시면 적어 둘 정보"가 적혀 있습니다. 분류 버튼 밑에는 완료 개수(`완료`, `0/2` 등)가 보이고, 첫 화면의 "예약 완료" 숫자도 여기서 셉니다(카드에 `data-count`가 붙은 것만). 비짓재팬은 사람별 체크(`v1~v3`)로 진행을 보여 줍니다. 예약 정보는 이 레포의 `index.html`에 들어 있어서 새 정보는 레포에서 고칩니다.

## 입력은 바로 저장돼요

- 쇼핑 탭의 추가 칸(이름·수량·금액)과 지출 기록의 입력 칸은 **쓰는 즉시** 임시 저장되어(`draft_g`, `draft_b`, `draft_x`), 사파리가 탭을 다시 불러와도 그대로 돌아옵니다. 추가하면 임시 저장은 지워집니다.
- 쇼핑 탭에서 **사진을 고르면 바로 항목으로 저장**됩니다(한 장에 항목 하나). 쓰던 이름·수량·금액이 있으면 그 값으로 만들어지고, 없으면 항목에서 적습니다. 항목의 수량·금액은 입력할 때마다 저장됩니다.
- 저장되면 화면 오른쪽 위에 "✓ 저장됨"이 잠깐 보입니다.
- 앱을 다시 열면(주소에 `#`가 없어도) 마지막으로 보던 탭, 예약·쇼핑의 하위 탭, 스크롤 위치(6시간 이내), 열어 둔 접이식 칸이 그대로 복원됩니다.

## 예약 서류(바우처·확인서) 보관

예약 카드의 점선 칸(`📎 바우처 올리기`)에서 PDF나 사진을 고르면 그 파일이 **이 폰의 IndexedDB에만** 저장되고, 카드에서 `📄 열기`로 새 탭에서 볼 수 있습니다(바꾸기·삭제 가능). 바우처에 PIN 같은 개인정보가 들어 있고 이 레포·사이트가 공개라서 파일 자체는 올리지 않습니다. 쇼핑 탭의 백업 파일에는 함께 들어가므로 다른 폰으로 옮길 수 있습니다. 예약번호 등 텍스트 정보는 카드에 직접 적혀 있습니다(PIN·확인키는 제외).

### 우버 프로모션 코드

예약·비용 탭의 "🚕 우버"에 프로모션 코드 8개가 대상별(공항, 신규 회원, 모든 회원, 기존 회원, 프리미엄)로 정리돼 있습니다. 코드 옆 `복사` 버튼이 클립보드에 담아 주고(구형 iOS는 선택 후 복사로 대체), 코드는 길게 눌러서도 복사됩니다. 횟수 제한이 있는 코드에는 "쓴 횟수" 체크 칸(`u_<코드>_<n>`)이 있어 쓴 만큼 체크해 둘 수 있고, 백업 파일에 같이 들어갑니다. 공항 코드(JPU1SW26AIR)는 10/4까지라 첫날 일정(공항 → 호텔)에도 안내가 붙어 있습니다.
